## Vulnerator 2.0 — 7.5.0 beta 5

**Find devices by registry number, and manage their other names.**

### What's new
- **Find box** above **Configuration Management > Hardware**. Type part of any of these to show only matching devices:
  - a name, another name, the FQDN or the NetBIOS name
  - the operating system or an IP address
  - a registry number, either `VUL-000123` or just `123`

  A registry number that was retired by a merge finds the device it was merged into.
- **Other names in the side panel.** Select a device to see its registry number and its other names.
  - **Add Name** saves another name for the device, such as the host name admins type into its checklists. Later
    imports with that name land on the device without a merge.
  - **Remove** forgets a name, such as one saved by a wrong merge.
  - A name that another record already has is refused. Merge the two records instead.

### Tests
- The checklist import test now checks:
  - a name that is the device's own or another record's is refused
  - a checklist with a hand-added name lands on the device
  - after the name is removed, that checklist becomes a new record
  - the Find matching on registry numbers (own and merged), names and addresses
