## Vulnerator 2.0 — 7.5.0 beta 2

**More Hardware columns, and Dashboards that match the same device across ACAS and STIG.**

### What's new
- **Configuration Management > Hardware > Columns...** shows or hides columns. Columns you can add:
  - Operating System (from ACAS / Nessus scans)
  - Last ACAS Scan, Last Checklist / SCAP, Last Scan and Scan Sources
  - Groups, Role, Manufacturer, Model, Serial Number, Virtual and Lifecycle Status

  Drag headers to reorder, and click a header to sort. Your choice is remembered.
- **Dashboards 1.1.0** (bundled, free):
  - **IAVMs** has a **Findings** column with the titles of the open findings behind each IAVM.
  - **Coverage** counts devices and shows each device's **operating system**, which hardware records make it up
    and where each record has data (for example `W01.Contoso.com (ACAS); W01.Contoso (STIG)`).
  - **Device matching:** records with the same short host name count as one device, so an ACAS scan of
    W01.Contoso.com and a checklist for W01.Contoso cover the same device. You can also:
    - turn short-name matching off
    - **Link** any two records as one device
    - **Keep separate** a match that is wrong

    These choices are saved in `Add-on data\dashboards\device-links.json`. They don't change the Hardware list or
    reports.

### Tests
- The checklist import test checks the last ACAS scan and last checklist dates per host.
- The Dashboards tests cover:
  - short-name matching (IP addresses are not matched by their first number), links, Keep separate and the saved file
  - the operating system column and the IAVM finding titles
