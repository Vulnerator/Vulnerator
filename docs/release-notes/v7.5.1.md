## Vulnerator 2.0 — 7.5.1

**Merging works again, a profile for each device, and one software entry per program.**

### Merge Ticked Hardware
- **Fixed:** merges stopped with "The database could not be backed up, so nothing was merged" whenever Vulnerator had
  the database open. The backup now uses SQLite's online backup, which takes a consistent copy while the database is in
  use.
- **Nothing to pick:** all the ticked records are combined into one device.
  - The device keeps the **oldest registry number**; the other records' numbers point to it.
  - When records have the same finding, the **newest result** is kept, with its POA&M and mitigation links.
  - The other records' names become the device's other names, so later checklists and scans with those names update it.
  - The window shows the device that remains and the records combined into it, with **Back up the database first**
    ticked by default.

### Device Profile
- The Hardware side panel is now **Device Profile / Add**. Double-click a device to open it.
- The top shows the registry number, the device's name, the numbers merged into it, and its last ACAS scan and last
  checklist / SCAP result.
- **FQDN** and **NetBIOS name** can now be edited, along with the name, scan IP, IP and MAC addresses, groups,
  software and ports. Choose **Add/Update Hardware** to save.

### Software: one entry per program
- When ACAS is not sure of a host's operating system, its scan lists every possible one on its own line. Each now
  becomes its own software entry, and the host's operating system shows them on one line ("A / B").
- **Software > Split Combined Entries** splits entries an earlier version saved together. Each new entry keeps the
  original's details and hardware links.

### Upgrading from 7.5.0
- Open your existing database as usual; nothing changes until you merge records or split entries.
- To fix software entries imported by 7.5.0 or earlier, choose **Split Combined Entries** on the Software tab once.
